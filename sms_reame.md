# Full-Stack School Management System (SMS)

## Tech Stack
- Frontend: React.js
- Backend: Node.js (Express)
- Database: MySQL

---

## Project Goal
Build a complete **full-stack School Management System** to help L5 SOD TVET students:
- Understand fullstack development flow
- Practice real exam-style features
- Apply React.js and Node.js together
- Gain confidence for national practical exams

---

## System User
### Admin (Only User)
The system is fully managed by the **Admin**.
There is **NO Student Login**.

---

## Main Features

### 1. Students Management
Admin can:
- Add student
- View students list
- Update student details
- Delete student

Student Information:
- Full Name
- Registration Number
- Gender
- Level / Class
- Combination

---

### 2. Teachers Management
Admin can:
- Add teacher
- View teachers list
- Update teacher details
- Delete teacher

Teacher Information:
- Full Name
- Email
- Phone Number
- Subject

---

### 3. Grades Management
Admin can:
- Add grades for students
- View grades list
- Update grades
- Delete grades

Grade Information:
- Student
- Subject
- Marks
- Grade (A, B, C, D)

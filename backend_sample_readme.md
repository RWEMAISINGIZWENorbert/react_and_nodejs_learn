# Backend Learning Steps (Node.js + MySQL)

## Goal
Learn backend development from zero to hero using Node.js, Express, and MySQL.
Focus is on practical skills for TVET national practical examinations.

---

## STEP 1: Backend Basics
- Understand what backend is
- Understand why backend is needed
- Know backend role in fullstack applications

---

## STEP 2: Node.js Fundamentals
- What Node.js is
- Why Node.js is used
- How Node.js works on the server

---

## STEP 3: MVC Backend Structure
- Understand MVC concept
- Model: database logic
- Controller: request handling logic
- Routes: URL mapping
- Importance of MVC structure

---

## STEP 4: Controllers
- What controllers are
- Why controllers are used
- Handling request and response
- Implementing CRUD logic

---

## STEP 5: Routes
- What routes are
- Why routes are needed
- Connecting routes to controllers
- REST API endpoints structure

---

## STEP 6: Project Setup
- Create project folder
- Initialize Node.js project
- Install dependencies:
  - express
  - mysql2
  - cors
  - dotenv
  - nodemon

---

## STEP 7: Project Structure
- src folder
- config folder
- controllers folder
- routes folder
- app.js
- server.js
- .env file

---

## STEP 8: MySQL Fundamentals
- What MySQL is
- Create database
- Create table
- Primary key concept

---

## STEP 9: Database Connection
- Create database connection file
- Connect Node.js to MySQL
- Test database connection

---

## STEP 10: TODO List Backend
- Create TODO table
- Create controller functions:
  - Get all todos
  - Add todo
  - Update todo
  - Delete todo
- Create routes for TODO APIs

---

## STEP 11: API Testing
- Use Postman
- Test all CRUD operations
- Handle errors

---

## STEP 12: Frontend Preparation
- Understand API endpoints
- Understand request body and response
- Ready to connect React frontend

---

## Final Outcome
Students will be able to:
- Explain backend structure
- Build Node.js backend projects
- Use MySQL database
- Create CRUD APIs
- Prepare for national practical exams

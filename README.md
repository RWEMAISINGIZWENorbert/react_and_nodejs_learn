# React.js Frontend Learning Process (Zero → Familiar)

## 🎯 Purpose of This Frontend Module

This module helps students **understand how React.js works** and
**practice UI design step by step**. The focus is on **doing**, not
memorizing theory.

By the end, We will be able: - Understand React basics - Design common UI
components - Build UI interfaces - Be ready for backend
integration later

------------------------------------------------------------------------

##  How We Will Learn

We follow the same process in every task:

1.  Understand the UI to build\
2.  Break it into components\
3.  Build the UI with React\
4.  Use state to make it interactive

## STEP 1: React Basics

### Goal

Understand how React works and how the UI updates automatically.

### Covered Topics

-   What React is
-   Components
-   JSX
-   Props
-   State (useState)
-   Events
-   Conditional rendering

### Practice

-   Button counter
-   Show / hide text
-   Simple reusable component

------------------------------------------------------------------------

## STEP 2: UI Form Components (Login & Signup)

### Goal

Learn how to design forms used in practical exams.

### Login Form UI

Includes: - Email input - Password input - Login button - Error message
placeholder

Concepts: - Controlled inputs - State handling - Form submission - Basic
validation

### Signup Form UI

Includes: - Full name - Email - Password - Confirm password - Signup
button

Concepts: - Multiple input states - Validation logic - Reusable
components

UI only --- no backend.

------------------------------------------------------------------------

## STEP 3: Simple TODO List App UI

### Goal

Understand lists and dynamic UI updates.

### Includes

-   Task input
-   Add task button
-   Task list
-   Delete task button
-   Empty list message

### Concepts

-   Arrays in state
-   Mapping data to UI
-   Conditional rendering

------------------------------------------------------------------------

## STEP 4: E-Commerce Home Page UI

### Goal

Learn layout and component composition.

### Sections

1.  Navbar (logo, links)
2.  Hero section (title, description, button)
3.  Product grid
    -   Image
    -   Name
    -   Price
    -   Add to cart button
4.  Footer

Concepts: - Props - Reusable components - Grid layout

------------------------------------------------------------------------

## STEP 5: Simple Admin Dashboard UI

### Goal

Practice dashboard UI design.

### Structure

-   Sidebar
-   Header
-   Main content

### Sidebar Menu

-   Dashboard
-   Students
-   Logout

### Header

-   Page title
-   Admin name

### Profile Section

-   Admin name
-   Role

### Dashboard Content

-   Summary card (Total students)
-   Students table:
    -   Name
    -   Registration number
    -   Level
    -   Action (Edit / Delete UI only)

Concepts: - Layout - Tables - Component reuse

------------------------------------------------------------------------

##  Learning Order

React Basics\
→ Login & Signup\
→ TODO List UI\
→ E-Commerce UI\
→ Admin Dashboard UI

------------------------------------------------------------------------

##  Final Outcome

As Students we will be able: - Understand React fundamentals - Design real UI
interfaces - Handle forms and lists - Build  practical-style
dashboards - Be ready for backend integration
